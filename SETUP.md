# GitHub Profile Package

Copy the contents of this folder into the `Santhoshmarkonda/Santhoshmarkonda` profile repository.

Structure:
- README.md
- assets/skills/*.svg
- assets/projects/*.svg
- assets/animations/*.svg

The SVG skill cards contain their own hover CSS and 3D icon rotation. GitHub may sanitize or ignore some interactive SVG behavior depending on its renderer; the cards still remain visually polished when static.

After pushing, open the profile README on GitHub and verify the asset paths. Keep the repository public.
